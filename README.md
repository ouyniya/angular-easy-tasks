# 📝 Angular Task Manager

A lightweight and modular task management application built with Angular.This project covers a wide range of Angular concepts such as components, services, directives, pipes, two - way binding, state management, content projection, and localStorage integration from the workshop section of “The Complete Guide to Angular” Udemy course —perfect for learning the Angular fundamentals.https://www.udemy.com/course/the-complete-guide-to-angular-2 โดย Maximilian Schwarzmüller 


### Credit

This project is based on the course["The Complete Guide to Angular"](https://www.udemy.com/course/the-complete-guide-to-angular-2/) by Maximilian Schwarzmüller.  

Code has been written for learning purposes and adapted with personal improvements.


## 🚀 Features

- ✅ Add, remove, and manage tasks
- 🔃 Two - way binding for task form input
- 🧠 Component communication(input / output & service - based)
- 🪝 Reactive form submission
- 🧱 Custom pipes, directives, and dynamic styling
- 💾 Data persistence using localStorage
- 🧼 Type - safe architecture using interfaces and type aliases

## 🧑‍💻 Getting Started

```bash
# Clone the repository
git clone https://github.com/yourusername/angular-task-manager.git

# Navigate into the project directory
cd angular-task-manager

# Install dependencies
npm install

# Run the app locally
ng serve
```

Visit http://localhost:4200 to view the application.
